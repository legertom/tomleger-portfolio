The building half

Work

Most of these run inside Clever, behind SSO — so they’re presented as case studies rather than live demos. The public ones are linked.

01

The AI Exchange

Internal · Clever · shipped v1 in ~1 month

Clever’s internal AI marketplace: employees publish and discover the tools, workflows, and prompts they’ve built, through semantic search and a catalog-grounded AI concierge.

The concierge agent runs with default tools disabled and only three grounded tools, with SSO enforced server-side — built for a high-security environment, not a demo.

02

Casespace

Internal · Clever · casebook + KR scoreboard + MCP server

The enablement program’s system of record: a use-case casebook and a live KR scoreboard, with a Claude-powered coach and an MCP server.

AI Leads file use cases directly from Claude Code — the tracking system lives where the work happens.

03

Formula Studio

Public · formulastudio.net

A workbench for Clever’s IDM formula language: playground, visualizer, training, REST + MCP APIs, and an AI assistant that only proposes locally verified formulas.

Guardrails as features: human-in-the-loop confirmation, fail-closed spend caps, rate limiting, and a documented threat model.

04

PMAT

21 lessons · github.com/legertom/clever-pmat-course

A 21-lesson course in a format I designed where Claude Code itself is the LMS — the tool people are learning is also the thing teaching them.

05

Citation-first RAG assistant

Internal · Clever · + remote MCP server

A citation-first RAG assistant and remote MCP server over Clever’s docs, used from Claude, VS Code, and Cursor — answers arrive grounded in the source, wherever people already work.

06

SSO Explorer & exampledistrict.com

Internal tooling · demo generator public at exampledistrict.com

Internal Clever tooling for troubleshooting complex SSO workflows, plus a generator for demo districts.

Cut integration-validation and troubleshooting time for the whole CS team.
